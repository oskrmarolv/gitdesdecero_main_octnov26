# Template: Branching

> Recomendacion para la estrategia de branching

## Patron de diseño

[ tematica ] / [ ticket ] / descripcion

`tematica`

* feature: indica desarrollo de una caracteristica en el software
* hotfix: correccion urgente en una version ya liberada
* release: indica una proxima liberacion
* environment: indica el entorno de despliegue

`ticket`

Indica el numero de issue/ticket que se relacion con una herramienta de planeacion (Jira, Monday, etc)

`descripcion`

Descripcion corta del issue/ticket. Normalmente se define con notacion CamelCase

Ejemplos:

* autenticacionConGoogle
* cambioModeloDatabase
