# README: GIT DESDE CERO

Primer archivo en el respositorio. Es "best-practice" crear un archivo `README` en cada repositorio.

## Lista de comandos

* git-init
* git-config
* git-add
* git-commit
* git-log
* git-status

Proximos:
* git-branch
* git-switch
* git-checkout
* git-remote
* git-diff
* git-show

## Best Practices

* Definir nomeclaturas claras que todos los desarrolladores deben implementar
  * nombres para las ramas
  * estructura de los commit's
* Siempre definir un archivo README.md (Sugerencia de notacion con Markdown)
* Siempre definir los valores de configuracion locales al repositorio
